AI Data Agent

固定工具检测、人工审批、模型编写源码、隔离执行与独立验证。 需要独立 Graph Runner 和 Docker worker；模型由服务端配置。

创建任务

业务目标目前仅作为任务描述保存，不会自动转换成清洗规则，也不会直接发送给模型。 请在后续审批中逐列选择并确认清洗动作和参数。

仅用于本地非敏感演示数据。当前接口使用原始 CSV 请求体；API 不解析 CSV 或执行代码，上传本身不会自动启动作业。

隐私与演示访问限制

当前为单用户演示：共享令牌的所有使用者均可访问同一所有者的任务，不提供多用户隔离。 页面可能显示业务目标、真实列名和数值范围；共享屏幕或截图前请检查内容。

清洗生成会发送匿名列索引、获批规则摘要及聚合统计。自愈时还会发送失败作业刚刚实际执行的完整源码及受限诊断，执行源码可能与模型原始输出不同。 系统不主动将原始 CSV 行、真实列名、填充值或原始异常消息与堆栈作为独立数据发送； 但若执行源码中包含这些内容或其他敏感信息，也会随源码一起发送。
