Use only non-sensitive demonstration data. The API accepts a raw CSV request body; it does not parse the CSV or execute code, and uploading alone does not start a job.

Privacy and demo access limitations

This is a single-user demo: everyone sharing a token can access the same owner's tasks. There is no multi-user isolation. The page may display business goals, real column names and numeric ranges; check the content before sharing your screen or screenshots.

Code generation sends anonymized column indexes, approved rule summaries and aggregate statistics. Repair also sends the complete source actually executed by the failed job and limited diagnostics; that source may differ from the model's original output. The system does not separately send raw CSV rows, real column names, fill values, raw exception messages or stack traces. However, these or other sensitive details will be sent if they appear in the executed source.
